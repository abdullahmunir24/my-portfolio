# Abdullah Munir - Personal Portfolio

Live site: [abdullahmunir.netlify.app](https://abdullahmunir.netlify.app)

A responsive personal portfolio website showcasing professional experience, projects, technical skills, and academic background.

## Built With

- **Core**: React, JavaScript (ES6+), HTML5, CSS3
- **Animations & Visuals**: Three.js, Typed.js, react-intersection-observer
- **UI Components**: react-scroll, @itseasy21/react-elastic-carousel, Font Awesome
- **Services**: EmailJS
- **Hosting & CI/CD**: Netlify

## Sections

- **Header**: Dynamic typography and interactive background canvas
- **About**: Background overview, interests, and personal highlights
- **Work Experience**: Professional roles and contributions with technology tags
- **Education**: Degree details, GPA, academic honors, and relevant coursework
- **Skills**: Interactive categorization across languages, frameworks, tools, and concepts
- **Projects**: Filterable showcase of featured full-stack and machine learning applications
- **Contact**: Functional email contact form and social profiles

## Getting Started

### Prerequisites

- Node.js (v18 recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abdullahmunir24/my-portfolio.git
   cd my-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install --legacy-peer-deps
   ```

### Development

To start the local development server:

```bash
npm start
```

The application will run at `http://localhost:3000`.

### Production Build

To generate an optimized production bundle:

```bash
npm run build
```

The compiled assets will be output to the `build/` directory.
